# 云上购物课 · AWS 交互复习

以 Amazon 电商购物为背景，串起已经学习的 AWS SAA 知识。具体服务搭配是教学设计，不代表 Amazon 完整内部架构。

## 本地打开

直接双击 `index.html` 即可使用；不需要安装依赖或连接 AWS。为使浏览器进度保存更稳定，推荐用本地服务器：

```sh
cd interactive_review
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8766/>。如果已有服务器从整个仓库提供页面，访问 `/interactive_review/`。

## 可以怎样学

- **购物旅程**：8 章、40 个步骤。点击服务节点查看解释；手动推进或自动播放请求路径。能复述原因后再标记本章已学。
- **故障实验**：5 个实验、24 个状态。改变 NAT 路由、缓存、健康检查、读取一致性与付款重试条件，观察图与结果变化。
- **知识树**：按业务问题组织服务，可展开或收起分支。
- **服务速查**：71 个知识条目，支持关键词和类别筛选。包含类比、具体用途、容易混淆的边界与官方文档链接。
- **综合测验**：20 道原创四选一，交卷前不展示答案、解析或知识点提示。可标记不确定、跳题、修改选择，全部交卷后复盘。

## 进度

学习完成标记、当前步骤、实验状态、作答与成绩保存在当前浏览器的 `localStorage` 中。更换浏览器、网址的端口或设备，进度不会自动同步。用右上角“导出进度 / 导入进度”迁移。

自动播放不会替你标记学完；测验得分也不等于 AWS 官方考试水平。

## 文件

```text
interactive_review/
├── index.html       页面入口
├── styles.css       自适应布局与视觉样式
├── app.js           图示、课程、实验、测验、进度功能
├── content.js       章节、服务解释、知识树与官方参考
├── labs.js          故障实验与状态
├── quiz.js          原创题目、答案与解析
├── favicon.svg      本地图标
├── tests/           数据一致性检查
└── README.md
```

普通 HTML、CSS 与 JavaScript，无构建流程、第三方 CDN、用户登录或后台服务。页面不会调用 AWS API；点击官方资料链接才会访问外部文档。

## 检查内容

如已安装 Node.js，可以运行：

```sh
node tests/validate.cjs
```

检查会校验章节、单步图、服务映射、实验连线与测验结构，不会连接网络。
